# GuidHubFront — Маршруты

> Переключатель «Клиент / Гид» — в шапке. Режим «Гид» доступен только при наличии роли Guide;
> иначе при переключении — предложение стать гидом, отказ → остаёмся в клиенте.

| Путь | Страница | Режим | Auth | Примечание |
|---|---|---|---|---|
| `/` | Приветственная | Клиент | Нет | Не каталог. Общая версия — по клику на логотип |
| `/u/:username` | Публичный профиль гида | Клиент | Нет | Точка входа по ссылке гида |
| `/events/:id` | Карточка мероприятия + слоты | Клиент | Нет | Ссылка гида на конкретное мероприятие |
| `/bookings` | Мои записи | Клиент | Да | Заявки клиента |
| `/profile` | Профиль | Клиент | Да | Данные, приватность, дети, удаление |
| `/profile/become-guide` | Стать гидом | Клиент | Да | POST /guides/become |
| `/guide/events` | Мои мероприятия | Гид | Да + роль | |
| `/guide/events/new` | Создание мероприятия | Гид | Да + роль | |
| `/guide/events/:id` | Управление мероприятием | Гид | Да + роль | Слоты, заявки |
| `/geography/request` | Заявка на изменение географии | Гид | Да + роль | |
| `/login` | Вход (Telegram Widget) | — | Нет | Шаг 6 |

## Открытые вопросы
- Нужен ли отдельный маршрут `/guide/bookings` (все заявки гида) или заявки живут внутри `/guide/events/:id`.
- Нужен ли `/settings` отдельно от `/profile`.
